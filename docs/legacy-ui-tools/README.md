# Historical frontend design tools

These tools and browser tests describe the previous local demonstration UI. They are retained as historical design evidence, outside the application package. They are not part of the live application or its verification commands, and many source paths refer to the earlier revision.

Current verification uses API/database integration tests, `apps/mobile/scripts/check-live-data.cjs` and the live browser suite. Do not use these generators to restore fixture-backed screens to the application.
