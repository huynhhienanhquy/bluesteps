# Hồ sơ frontend

Chỉnh tên, ngày sinh, quốc gia, giới thiệu, email hiển thị và ảnh đại diện được lưu cục bộ theo tài khoản trên ứng dụng hoặc trình duyệt. Có chọn/chụp ảnh, xem trước và gỡ ảnh. Email đăng nhập thuộc phiên xác thực hiện có. Đã gỡ API và migration thêm riêng cho hồ sơ ở lượt trước.

Không chạy kiểm thử theo yêu cầu.
